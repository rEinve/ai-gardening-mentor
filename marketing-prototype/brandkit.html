11Responsive behavior

One grid, four viewport tiers

The shared layout classes change their column spans at the Composer’s Compact, Medium, Expanded, and Large breakpoints.

Name Width Grid classes Behavior
Compact 0–599px .com-col-* Compact spans set the column width on small screens.
Medium 600–839px .md-col-* Medium spans apply from the 600px media query.
Expanded 840–1199px .exp-col-* Expanded spans apply from the 840px media query.
Large 1200px and up .lg-col-* Large spans apply from the 1200px media query.

Touch targets

  • Keep primary controls at least 44 × 44px where the layout allows.
  • Retain a visible focus state for keyboard users.

Grid behavior

  • Grid items default to full width until a breakpoint span applies.
  • Each larger tier can set a new span with its matching class prefix.
  • Component styles may use additional local media queries for navigation, type, or spacing.

Breakpoint widths match the Composer viewport tiers and the shared IntelliTheme grid media queries.
